**Interpretation:**
- All three pipelines run end-to-end on the cluster in the `longcat` env; imports
  / signatures / geometry all wired correctly. SAVi-DNO's **fair leakage-free
  protocol is confirmed active** (`protocol=fair_streaming_observed_history`,
  `leakage_free=True`) and fits in 2xH200 with ~50 GiB headroom.
- **Two real issues surfaced (both about SAVi-DNO), which is exactly why we
  smoke-tested:**
  1. **SAVi-DNO saved 0 videos.** By design its old code only wrote an mp4 when
     the id was in `--save-only-list`; there was NO save-all path. This would
     have lost every SAVi video for the figure bank / future experiments (the
     same class of mistake as the earlier NO_SAVE_VIDEOS incident).
  2. **SAVi-DNO computed no VBench** — its metric path (PSNR/SSIM/LPIPS/FVD/FID)
     is self-contained and never touched the shared VBench harness, so it had a
     different metric set than the AdaSteer runs.
- **Quality caveat (NOT yet resolved):** PSNR 8.35 / SSIM 0.05 / LPIPS 0.85 are
  very poor. Partly expected for a smoke (6 Euler steps, 2 rollout steps, and the
  differentiable sampler runs CFG-off), but SSIM ~0.05 is low enough that SAVi-DNO
  must be validated at production settings (>=10 Euler / >=10 rollout) AND against
  its own `--no-optimize` LongCat baseline on the same clips before we trust it as
  a paper baseline. If `--no-optimize` scores similarly low, the culprit is the
  undercooked/CFG-off generation, not the noise optimization.

**Action taken:**
- Added `--save-videos` (save ALL generated mp4s) to `savi_dno_longcat.py`;
  kept `--save-only-list` as the selective option.
- Added `--compute-vbench` to `savi_dno_longcat.py`: post-hoc VBench++ (same 7
  dims as AdaSteer) on the saved mp4s, guarded, does not touch FVD/FID/PSNR.
- `run_savi_dno_longcat.sbatch` now defaults to save-all + VBench
  (`SAVI_NO_SAVE_VIDEOS=1` / `SAVI_COMPUTE_VBENCH=0` to opt out); banner prints
  the save/VBench status.
- Smoke sbatch now passes `--save-videos` to SAVi so the next smoke verifies
  saving works.
- **Still TODO:** production-settings SAVi sanity run + `--no-optimize` control
  before committing to the full 1000v SAVi launch.
